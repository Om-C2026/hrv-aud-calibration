# hrv-aud-calibration
HRV calibration and ML classification for AUD relapse monitoring. ECG-to-PPG calibration achieving gold-standard performance (AUC=0.85). Includes feature extraction, Random Forest/SVM/LSTM/CNN models, and 7-day Empatica vs Fitbit cross-device comparison. Under review at PLOS ONE (PONE-S-26-64505).
